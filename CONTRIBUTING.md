# Contributing to Coding Protocols (Internal)

This guide is for the core engineering team. All members are expected to uphold the [Code of Conduct](CODE_OF_CONDUCT.md).

## Internal Workflow

1.  **Direct Push (Protected Branches)**: For routine metadata updates, use short-lived branches and PRs reviewed by at least one other team member.
2.  **Infrastructure Changes**: All major changes to org-wide health files or GitHub Actions must be reviewed by the security team.
3.  **Branding and Assets**: Use the pre-approved SVGs and high-performance image formats (WebP format preferred for non-vector assets).

## Principles

- **Precision**: Maintain exactness in our public-facing documentation.
- **Stability**: Ensure all org-level configuration is stable and scales across repositories.
- **Security**: Treat all infrastructure-as-code and org-metadata with high confidentiality.
