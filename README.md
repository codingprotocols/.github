# Coding Protocols — Infrastructure

> [!IMPORTANT]
> This repository is for internal organization management and is maintained exclusively by the Coding Protocols core team.

The standard-grade infrastructure repository for the Coding Protocols organization. 
This repository contains organization-wide metadata, profile information, and shared health files that apply across the fleet.

## Components

- `profile/`: The organization's public profile README.
- `img/`: Brand-authentic assets used in organization profiles.

## Governance

Maintenance and updates to these files are restricted to the primary engineering team. For project-specific contributions, please refer to the individual product repositories (e.g., [Podscape](https://github.com/codingprotocols/podscape)).
